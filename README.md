## 🛠️ Build

</div>

```bash
git clone https://github.com/IqwanXD/SenseiX.git
cd SenseiX
./gradlew assembleDebug
```

<div align="center">

APK hasil build ada di `app/build/outputs/apk/debug/`.
Build otomatis juga tersedia lewat tab **Actions**.
