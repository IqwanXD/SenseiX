## 📱 Tentang

**SenseiX** adalah aplikasi Android yang dibangun menggunakan Gradle dan dikompilasi otomatis lewat GitHub Actions.

## ✨ Info Singkat

| | |
|---|---|
| **Nama** | SenseiX |
| **Platform** | Android |
| **Build System** | Gradle |
| **CI/CD** | GitHub Actions |
| **Branch Utama** | `master` |

## 🛠️ Build

```bash
# Clone repo
git clone https://github.com/IqwanXD/SenseiX.git
cd SenseiX

# Build APK debug
./gradlew assembleDebug
```

APK hasil build ada di `app/build/outputs/apk/debug/`.

> Build otomatis juga tersedia lewat tab **Actions** di repository ini.
